## 目标

为 kk-electric.com 获取高质量、相关性强、可持续的外链，提升：
- **Google 搜索排名**（核心 5-10 个 AVR 关键词）
- **AI 引擎品牌提及**（ChatGPT / Perplexity / Claude / Gemini）
- **目标市场信任度**（非洲 + 中东 + 南亚 + 东南亚）

## 关键约束

- **只做 YOKE AVR 业务相关**：voltage stabilizer / voltage regulator / 电力质量
- **不做**钢价 / 紧固件 / 不相关行业
- **不付费买链**（Google Penguin 风险，长期 ROI 低）
- **优先白帽 + 高相关性**：宁可少 5 个低质外链，不要 50 个垃圾外链
